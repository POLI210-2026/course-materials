Run setup first and the numbered sections in order. See START-HERE.txt.

  quarto render data-wrangling-slides.qmd --to revealjs
  quarto render data-wrangling-slides.qmd --to typst
  quarto render data-wrangling-live-demo.qmd --to html

The PDF is the approved printable slide export. The HTML demo contains code
and saved output. data/SOURCES.txt documents provenance and preparation.
