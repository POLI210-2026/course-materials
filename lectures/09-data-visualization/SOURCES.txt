9,337 district-elections, 1946–2014; 328 rows in 2014. Not an election census.
dv/dvp: current/prior Democratic House two-party vote percentage.
dpres: Democratic presidential two-party vote percentage in current/most recent
presidential election; 1,125 missing values. Never recode these to zero.
state is alphabetical state index, NOT FIPS; stcd=state*100+district.

elections-nominate.csv is generated by private R/prepare-data.R. Following
Congress=(election year-1786)/2. Join on Congress, state abbreviation, district.
Only single-member-record keys receive scores. No heuristic at-large recoding;
multiple-member and missing keys remain flagged. Left join preserves all 9,337
rows: 9,149 matched, 167 ambiguous, 21 no exact key. The ideology plot additionally
requires observed dpres, leaving 8,061. NOMINATE describes members' roll-call
positions, potentially using career information, not pre-election voter ideology.
Use matched comparisons descriptively, not as causal estimates.
