POLI 210 — Seminar 9: Data visualization with ggplot2
October 28, 2026

Student downloads and links:
https://poli210-2026.github.io/course-materials/meetings/09-data-visualization/

For the R demonstration, download seminar9-demo.zip and extract the whole
archive. Open poli210-seminar9.Rproj, then data-visualization-demo.qmd.
Follow the package setup instructions and run the sections from the top.
The QMD depends on R/setup.R and the CSVs in data/. The QMD alone is not
a complete runnable project.

Editable teaching sources are included here. From this directory:
  quarto render data-visualization-slides.qmd --to revealjs
  quarto render data-visualization-slides.qmd --to typst
  quarto render data-visualization-demo.qmd --to html

The PDF is the approved printable slide export. The HTML demo contains code
and saved output. SOURCES.txt documents data provenance and matching choices.
The frozen teaching data are supplied; rebuilding the original data extract
is not necessary to run the demo or render these materials.

Private instructor notes and preparation files are not distributed.
B4 will be released separately through private student repositories.
