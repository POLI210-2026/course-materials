# POLI 210 course materials  -  Fall 2026

This public repository contains the syllabus, meeting materials, computing
setup guides, and shared resources for **POLI 210: Quantitative Analysis of
Political Data I** at UC Merced.

Course website: <https://poli210-2026.github.io/course-materials/>

## What is not stored here

Assignments are distributed through private GitHub repositories created for
each student. Solutions, grades, exams, student information, and restricted
readings are not stored in this public repository. CatCourses remains the
official location for announcements, grades, and protected course content.

## Local preview

Open a Terminal in the repository and run:

```bash
quarto preview
```

Render the publishable site into `docs/` with:

```bash
quarto render
```
